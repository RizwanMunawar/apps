# Redact releases

Public download host for [Redact](https://rizwanai.com/redact), a free macOS app that blurs
faces and objects live on your webcam, entirely on-device.

This repo holds nothing but release binaries. The source lives in
[`RizwanMunawar/rizwanai/apps/redact`](https://github.com/RizwanMunawar/rizwanai/tree/main/apps/redact)
(that repo is private, so its Releases aren't publicly downloadable — this repo exists so the
`.dmg` link on the landing page works for anyone, not just the repo owner).

Download the latest `.dmg` from [Releases](https://github.com/RizwanMunawar/redact-releases/releases/latest).
