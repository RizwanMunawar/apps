# apps-releases

Public download host for the small apps at [rizwanai.com](https://rizwanai.com). This
repo holds nothing but release binaries, no source. Each app tags its releases as `<slug>-vX.Y.Z` (e.g. `redact-v1.0.0`), so multiple apps can share
this one repo's Releases page instead of needing a repo each.
