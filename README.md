# apps-releases

Public download host for the small apps at [rizwanai.com/apps](https://rizwanai.com/apps). This
repo holds nothing but release binaries — no source.

Each app tags its releases as `<slug>-vX.Y.Z` (e.g. `redact-v1.0.0`), so multiple apps can share
this one repo's Releases page instead of needing a repo each.

| App | Source | Releases |
| --- | --- | --- |
| [Redact](https://rizwanai.com/apps/redact) | [`rizwanai/apps/redact`](https://github.com/RizwanMunawar/rizwanai/tree/main/apps/redact) (private) | [redact-*](https://github.com/RizwanMunawar/apps-releases/releases?q=redact-&expanded=true) |

Source for each app lives in [`RizwanMunawar/rizwanai`](https://github.com/RizwanMunawar/rizwanai)
under `apps/<slug>` (that repo is private, so its own Releases aren't publicly downloadable —
this repo exists so the download link on each app's landing page works for anyone, not just the
repo owner).
